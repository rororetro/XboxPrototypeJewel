# XboxPrototypeJewel
Code and tools for a Raspberry Pi Pico 2 firmware, to encode and play animations on the jewel of the [Macho Nacho Productions Xbox Prototype Recreation](https://www.youtube.com/watch?v=0OMP8JvGWNY).

### pico_fw
The firmware that runs on the Pico 2 to decode the video and output the Enhanced DVI signal used to drive the display.

### video_compressor
Python code to compress 800x800 videos (most formats supported) into the format used on the Pico 2.
